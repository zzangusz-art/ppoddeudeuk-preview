이 표의 금액만 더해서 4시간권 기준으로 세 가지 경우를 계산해 봤습니다.

1. 보드를 처음 타는 대학생: 프리미엄 초급자 보드 15,000원 + 프리미엄 의류 20,000원 + 헬멧 5,000원 = 40,000원입니다. 정상가로 계산하면 20,000원 + 30,000원 + 10,000원 = 60,000원입니다.
2. 몇 시즌 타 본 중급자: 프리미엄 중급자 스키 25,000원 + 하이엔드 의류 30,000원 + 헬멧 5,000원 = 60,000원입니다. 정상가로는 30,000원 + 40,000원 + 10,000원 = 80,000원입니다.
3. 헬멧은 챙겨 오는 상급자: 하이엔드 상급자 스키 40,000원 + 프리미엄 의류 20,000원 = 60,000원입니다. 정상가로는 50,000원 + 30,000원 = 80,000원입니다.
